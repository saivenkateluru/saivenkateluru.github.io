## 1. Sequences require memory

Let a sequence be $x_{1:T}=(x_1,ldots,x_T)$, where $x_t\in\mathbb{R}^{d_x}$. A feed-forward network treats inputs independently, but language does not: the interpretation of $x_t$ depends on what came before it. A recurrent neural network introduces a state $h_t\in\mathbb{R}^{d_h}$:

$$
h_t=\phi(W_xx_t+W_hh_{t-1}+b), \qquad y_t=g(W_oh_t).
$$

The state is a learned summary of the prefix $x_{1:t}$. Parameters are shared across time, so the same transition rule can process sequences of different lengths.

### The ideal goal

We would like $h_t$ to retain every earlier fact relevant to future predictions. But both information and gradients must repeatedly pass through the same transition. For a loss $L$ at time $T$,

$$
\frac{\partial L}{\partial h_t}
=
\frac{\partial L}{\partial h_T}
\prod_{k=t+1}^{T}\frac{\partial h_k}{\partial h_{k-1}}.
$$

If the Jacobian factors usually have norm below one, the product shrinks exponentially: the gradient vanishes. If they have norm above one, it can explode. Long-range credit assignment is therefore difficult even before we ask whether one fixed-size vector can preserve a long sentence.

<div className="takeaway">The RNN's strength and weakness are the same: every token is forced through one recurrent state.</div>

## 2. LSTMs and GRUs improve the memory mechanism

The Long Short-Term Memory network introduces a cell state $c_t$ with an additive update path. One common formulation is

$$
\begin{aligned}
f_t &= \sigma(W_f[x_t,h_{t-1}]+b_f),\\
i_t &= \sigma(W_i[x_t,h_{t-1}]+b_i),\\
\tilde c_t &= \tanh(W_c[x_t,h_{t-1}]+b_c),\\
c_t &= f_t\odot c_{t-1}+i_t\odot\tilde c_t,\\
o_t &= \sigma(W_o[x_t,h_{t-1}]+b_o),\\
h_t &= o_t\odot\tanh(c_t).
\end{aligned}
$$

The forget gate $f_t$ decides what survives, the input gate $i_t$ decides what is written, and the output gate $o_t$ decides what is exposed. Most importantly,

$$
\frac{\partial c_t}{\partial c_{t-1}}=f_t,
$$

so the model can learn a nearly identity gradient path by keeping $f_t\approx 1$.

The Gated Recurrent Unit simplifies this idea by merging cell and hidden state:

$$
\begin{aligned}
z_t &= \sigma(W_zx_t+U_zh_{t-1}),\\
r_t &= \sigma(W_rx_t+U_rh_{t-1}),\\
\tilde h_t &= \tanh(W_hx_t+U_h(r_t\odot h_{t-1})),\\
h_t &= (1-z_t)\odot h_{t-1}+z_t\odot\tilde h_t.
\end{aligned}
$$

Both architectures make memory easier to preserve. Neither removes the sequential path $h_{t-1}\to h_t$: step $t$ still waits for step $t-1$, and distant information still travels through many transitions.

## 3. Encoder-decoder models expose a second bottleneck

For sequence-to-sequence learning, an encoder RNN reads $x_{1:T}$ and a decoder predicts $y_{1:S}$. The naive design gives the decoder only the final encoder state:

$$
c=h_T^{\text{enc}},\qquad
p(y_s\mid y_{<s},x_{1:T})
=p(y_s\mid y_{<s},c).
$$

This asks one vector $c$ to represent every source token, regardless of sequence length. Gating improves transport through time, but it does not remove this fixed-vector compression.

### Question: must the decoder use the same summary for every output token?

No. When producing $y_s$, let it retrieve the encoder states most relevant to that output.

## 4. Attention begins as retrieval over RNN states

Let encoder states be $h_1,ldots,h_T$ and decoder state be $s_{s-1}$. Define an alignment score

$$
e_{s,t}=a(s_{s-1},h_t),
$$

normalize scores across source positions,

$$
\alpha_{s,t}
=\frac{\exp(e_{s,t})}{\sum_{j=1}^{T}\exp(e_{s,j})},
\qquad
\sum_{t=1}^{T}\alpha_{s,t}=1,
$$

and compute a decoder-specific context,

$$
c_s=\sum_{t=1}^{T}\alpha_{s,t}h_t.
$$

The decoder now receives a soft retrieval result rather than one permanent summary. The weights $\alpha_{s,t}$ are learned end-to-end and vary with the output position $s$.

This is still an RNN system: recurrence constructs the encoder and decoder states. Attention solves the fixed-context bottleneck, but the recurrent backbone remains.

<div className="takeaway">Attention first changed how the decoder reads memory; it did not initially replace the recurrent machine that created that memory.</div>

## 5. From alignment to query, key, and value

The retrieval operation becomes clearer when written using three roles. A query $q$ represents what the current position seeks; keys $k_t$ describe what each position offers for matching; values $v_t$ contain what will be retrieved.

For matrices $Q\in\mathbb{R}^{n_q\times d_k}$, $K\in\mathbb{R}^{n_k\times d_k}$, and $V\in\mathbb{R}^{n_k\times d_v}$,

$$
\operatorname{Attention}(Q,K,V)
=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.
$$

The matrix $QK^\top$ contains every query-key compatibility. Division by $\sqrt{d_k}$ prevents dot-product variance from growing with dimension and pushing softmax into saturated regions.

If $Q$, $K$, and $V$ are all projections of the same sequence $X\in\mathbb{R}^{T\times d_{\text{model}}}$,

$$
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V,
$$

the operation is **self-attention**. Every token can directly aggregate information from every other token in one layer.

## 6. The Transformer asks whether recurrence is still necessary

Once self-attention can mix sequence information, recurrence is no longer the only mechanism available. The Transformer encoder layer uses

$$
\begin{aligned}
H' &= \operatorname{LayerNorm}\left(H+\operatorname{MultiHeadAttention}(H)\right),\\
H^{\text{out}} &= \operatorname{LayerNorm}\left(H'+\operatorname{FFN}(H')\right).
\end{aligned}
$$

Multi-head attention performs several learned retrievals in parallel:

$$
\operatorname{MultiHead}(Q,K,V)
=\operatorname{Concat}(\text{head}_1,\ldots,\text{head}_m)W_O.
$$

Because self-attention alone is permutation-equivariant, position must be supplied separately, for example by adding positional encodings to token embeddings. The decoder adds causal masking so position $t$ cannot read future positions.

The computational path between two tokens is now $O(1)$ layers rather than $O(T)$ recurrent transitions. All positions in a layer can be computed in parallel, although full attention requires $O(T^2)$ pairwise scores.

## Where we stop

The historical progression is not “RNNs failed, so Transformers won.” It is more precise:

1. RNNs introduced a learned state for variable-length sequences.
2. LSTMs and GRUs improved gradient and memory transport.
3. Encoder-decoder attention removed the single-context bottleneck.
4. Self-attention turned retrieval into the sequence-mixing operation itself.
5. The Transformer removed recurrence and supplied position separately.

<div className="takeaway">The decisive step was not inventing attention; it was recognizing that attention could carry the sequence interaction previously assigned to recurrence.</div>

## Quick summary

- RNN: $h_t$ compresses the prefix but creates a long sequential path.
- LSTM/GRU: gates improve memory preservation but retain recurrence.
- RNN attention: each decoder step retrieves a weighted combination of encoder states.
- Self-attention: tokens retrieve directly from tokens using queries, keys, and values.
- Transformer: self-attention + position information + feed-forward blocks, without recurrence.
